# 初始工作流设计

- 日期：2026-08-17
- 范围：可移植开发工作流包与 BookReader 首次接入
- 工作流等级：重大

## 意图与边界

创建与厂商无关的 `AGENTS.md` 加按需 Skill 工作流。优先把资源用于真实项目工作，避免强制通读文件、重复验证和例行文档改写。

## 设计决策

- 将任务判级和路由保留在始终加载的文件中。
- 使用四个职责明确的 Skill，不做一个巨型 Skill，也不拆成大量微型 Skill。
- L0/L1 不必加载 Skill 即可执行。
- 按所有权路由项目知识，仅在实际受到影响时更新。
- 将项目专属规则放在独立受管区。
- 面向人的内容使用中文，仅保留必要的英文路径、名称和技术标识。

## 验证

校验全部 Skill，编译 Python 脚本，验证安装预演与审计，并以 BookReader 作为首个真实接入项目。

## 剩余风险

不同 Agent 对隐式 Skill 激活的实现存在差异，因此 `AGENTS.md` 要求在不支持原生加载时直接阅读对应 `SKILL.md`。
