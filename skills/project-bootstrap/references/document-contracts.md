# 文档职责

每类持久事实只由一个文档负责。

| 文档 | 负责内容 | 不应包含 |
|---|---|---|
| `README.md` | 用途、安装、命令、运行方式、用户入口 | 架构理由和调查历史 |
| `DESIGN.md` | 目标、非目标、行为、用户流程、需求、验收 | 包目录树和按时间排列的实现记录 |
| `ARCHITECTURE.md` | 组件、边界、状态所有权、数据流、协议、不变量 | 产品待办和安装教程 |
| `LEARNING.md` | 可搜索、非显然、可复用的项目经验 | 例行变更和原始调试流水 |
| `docs/traces/*.md` | 单次复杂调查或变更的证据与过程 | 通用项目说明 |
| `docs/decisions/*.md` | 持久决策、备选方案及其后果 | 临时计划和实施日记 |

只创建确有必要的文档。优先完善已有权威来源，不增加相互竞争的文件。
